# ADR-0048：外部測試專案預設放在原專案被 Git 忽略的目錄

## Context

ADR-0008 把外部測試專案放在原 repo 之外，測試專案的位置需要另外記錄，引用被測專案的相對路徑在任一邊搬動後失效。ADR-0008 的不侵入邊界以原專案版控內的追蹤檔案不變為準，被 Git 忽略的目錄不影響這個邊界。當時的來源：使用者於 2026-11-23 的對話提出預設放在 `.local`、建立時先詢問位置，並要求評估兩種放法的實務風險。

## Decision

`legacy-test-harness` Skill 的測試專案預設放在原專案被 Git 忽略的 `.local` 下，建立前確認這個位置不影響原專案的版控與建置，並取得使用者對位置的確認，條件不成立時放在原 repo 之外。原專案追蹤檔案不變、相依在測試端切斷，以及交給整合測試 Skill 的分界沿用 ADR-0008。

- 預設放在原 repo 之外：與原專案的建置設定互不干擾，但位置與引用路徑需要在每台電腦各自維護。

## Consequences

測試專案沒有原專案的版控紀錄，原專案清除被忽略的檔案時會一併刪除它，需要歷史紀錄時在測試專案目錄另建 repo。位置的確認項目與建置設定的隔離方式見 `skills/legacy-test-harness/SKILL.md`「外部測試專案與原專案保護」。把測試專案移到原專案受版控追蹤的目錄，或略過位置確認，都違反這個決定。
