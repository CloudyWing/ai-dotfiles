# ADR-0045：授權依能否復原與影響範圍分類

## Context

授權依動作種類要求，修改規則檔、清除自建的暫存與落地到整合分支都需當輪授權。使用者不在時整項工作停住，而這些動作多數可由 git 還原。

## Decision

授權改依能否復原與影響範圍分類。只影響線分支、線工作樹、本流程自建資源或本機整合分支的動作不需授權；會影響遠端、發佈內容或環境的動作（push、發佈、安裝套件、刪除非本流程建立的資源、advisor 諮詢）須使用者當輪直接授權。排除的方案是維持依動作種類分類，因為可還原的動作也要等待使用者。

## Consequences

把關集中在 push 與發佈，規則檔的改動可在使用者看過之前進入線分支與本機整合分支，由必發審查與 push 授權請求補償。條文以 `rules/claude/20-coordination.md`「授權分類」為準。ADR-0039 的不可轉述清單中「整合分支落地與合併」不再適用，其餘維持有效。
