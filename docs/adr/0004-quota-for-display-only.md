# ADR-0004：額度只供顯示與紀錄

## Context

派工曾以額度門檻決定是否派工、縮小範圍或停機，並以校準樣本估算每段工作的額度用量，但門檻多次讀錯 primary 與 secondary 視窗、造成派工死鎖，校準樣本也因快照新鮮度規則長期無法累積到可用筆數。使用者以重置券自行管理額度，自動停派反而中斷工作。

## Decision

額度快照只由 `Get-CodexQuota.ps1` 向 `/wham/usage` 即時取得，用於派工前、advisor 諮詢前、長時間派工期間與結案時的顯示與紀錄，不作為派工放行條件，也不改寫派遣單宣告的範圍。查詢失敗、快照過期或視窗重設時記為 unknown 並照常派工；服務端明確拒絕時保存已確認成果與未完成單位，不重試。排除的方案為額度門檻、校準樣本與 Budget 停機控制，三者已自腳本移除。

## Consequences

派工不再因額度狀態被擋或被縮小，額度是否足夠由使用者判斷，額度耗盡造成的中止由中斷保全與 failure receipt 承接。每次派工仍保存 before 與結案快照、ScopePlan 與 usage 作為成本紀錄，需求級的成本累計由協調者寫入同線 `cost-ledger.md`。
