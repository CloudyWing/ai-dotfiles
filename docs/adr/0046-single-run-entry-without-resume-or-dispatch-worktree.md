# ADR-0046：Codex 派工改為單次唯讀執行，不續行、不建立派遣 worktree

## Context

ADR-0042 之後 Codex 不再修改原始碼，只剩唯讀的測試取證、審查、顧問、事實校閱與影像產生，失敗時重跑的代價變小。舊入口 `Invoke-CodexDispatch.ps1` 為了保護寫入派遣而有派遣 worktree、續行鏈、owner 接手與結果檔提交等機制，維護成本已高於它們帶來的保護。當時的來源：ADR-0042、`326c419` 至 `8e67328` 的 commit、使用者 2026-11-18 的指示，考量由使用者於 2026-11-20 確認；本份為補記。

## Decision

Codex 派工由 `scripts/Invoke-CodexRun.ps1` 以單次執行承接，直接在線工作樹唯讀執行，不建立派遣 worktree，失敗時整筆重跑、不續行，舊入口與其機制整個移除。做法見 `skills/codex-dispatch/references/run.md`。

- 保留舊入口作為回退：各任務類型切換完成後舊入口已沒有呼叫端，保留只增加維護面。
- 等另一台電腦確認後再刪：使用者指示不等，直接刪除。
- 舊入口的本機殘留繼續由腳本辨識與保護：使用者指示用不到的都刪除，各電腦的殘留自行處理。

## Consequences

ADR-0005、0006、0022、0024、0025、0026 所記的機制不再存在，ADR-0040 的提案不採行，這七份由本份取代。日後不為了節省重跑成本而在入口加回續行，也不為了隔離而建立派遣 worktree；需要讓 Codex 修改原始碼時依 ADR-0042 的做法。
