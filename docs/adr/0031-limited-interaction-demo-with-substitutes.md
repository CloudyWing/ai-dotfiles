# ADR-0031：Demo 以替身加有限互動呈現，不預覽真實元件

## Context

Demo 以純 HTML 呈現，無法載入專案框架的元件。若為了逼近真實行為而自行設計日曆等能力，會產生與系統相異的樣式與操作流程，並在已確認的設計之外新增未驗收的內容。

## Decision

框架元件以替身呈現，外觀取自基準的樣本頁，操作與能力依元件契約，並逐畫面記錄替身名稱、樣本路徑、契約來源與真實元件差異。互動只開放切頁、頁籤、展開、彈窗與驗證回饋五種操作的子集，每項須有基準記錄或使用者確認的來源，未記錄的能力填入待確認並交回協調者。外框採註解與操作互斥，開啟註解時畫面唯讀，重載本機畫面重設狀態，排除以焦點轉移自動關閉註解。

## Consequences

替身清單、固定資料與允許操作只放 `demo-data.js` 與 Prototyper 回報，外框只顯示待確認項。樣本無 JavaScript 而無法重現的外觀須列入差異，交付前由協調者釐清，不宣稱已相符。
