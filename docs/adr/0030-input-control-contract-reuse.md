# ADR-0030：輸入控制項依基準的元件契約沿用

## Context

日期、時間與下拉選單等控制項，專案常以封裝元件、第三方外掛或原生控制項實作，只對齊色彩與間距而改用 HTML5 原生 input，會讓畫面偏離專案既有的操作方式與值格式。目標 app 的技術棧也不一定是 Vue。

## Decision

`uiux-baseline` 依來源證據判定封裝元件、第三方外掛、原生控制項或伺服器渲染，並在基準記錄每個元件的名稱、來源、註冊方式、必要資源、顯示格式、綁定值格式與空值語意。設計與實作沿用契約指定的元件連同必要資源與值語意，涉及輸入控制項的 T-code 附上固定格式的元件沿用標註。契約缺少、矛盾或待決策值未確認時，保留未決並停止該項，排除預設 Vue 元件與新增檢查腳本。

## Consequences

基準掃描多一份元件契約與靜態樣本頁，需要初始化才能呈現的外觀只能記為「靜態樣本無法重現」。T-code 的元件沿用標註成為 Developer 與 Reviewer 核對的依據。
